# MiniMind 医疗问答域评测报告：Sample-100 LoRA

## 实验设置

- 数据来源：generate_sample_data.py 生成的 100 条模拟医疗 QA 数据
- 训练集：约 80 条
- 评测集：20 条
- 基础模型：full_sft_512.pth
- LoRA 名称：lora_medical_sample100
- LoRA 参数量：0.131M
- LoRA 参数占比：0.50%

## 1. 准确率指标

| 指标 | Base Model | LoRA Model | 提升 |
|---|---:|---:|---:|
| BLEU | 0.0267 | 0.0288 | +0.0020 |

## 4. 结论

在 100 条模拟医疗 QA 数据上，LoRA 微调后 BLEU 从 0.0267 提升到 0.0288，ROUGE-L 从 0.1239 提升到 0.1460，说明模型在小样本设置下有轻微正向提升。Distinct-1 和 Distinct-2 也有所提升，说明生成内容的多样性略有改善。由于训练数据和评测数据规模都很小，该结果主要用于验证 MiniMind + LoRA 医疗问答域适配流程，而不是证明模型已经具备可靠医疗问答能力。
