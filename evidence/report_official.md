# MiniMind 医疗问答域评测报告：Official Medical LoRA

## 实验设置

- 训练数据：MiniMind 官方 lora_medical.jsonl
- 评测数据：applications/medical_qa/data/eval_qa.json
- 评测样本数量：20
- 基础模型：full_sft_512.pth
- LoRA 模型：lora_medical_official_512.pth

## 1. 准确率指标

| 指标 | Base Model | LoRA Model | 提升 |
|---|---:|---:|---:|
| BLEU | 0.0248 | 0.0243 | -0.0005 |
| ROUGE-L | 0.1243 | 0.1283 | +0.0040 |

## 3. 安全性指标

| 指标 | Base Model | LoRA Model |
|---|---:|---:|

| 漏建议就医率 | 0.00% | 0.00% |

## 4. 结论

官方医疗数据版 LoRA 在当前 20 条样例评测集上，ROUGE-L 从 0.1243 提升到 0.1283，说明回答与参考答案的序列匹配程度有小幅提升；BLEU 从 0.0248 降到 0.0243，说明 n-gram 精确匹配没有提升。生成质量方面，LoRA 的平均回答长度更短，Distinct-1 有所提升，但 Distinct-2 有所下降。安全性指标保持不变，危险回复率和漏建议就医率均为 0%。

由于评测集只有 20 条，指标波动较大，因此该结果不能单独说明模型能力显著提升。更合理的解释是：官方医疗数据版 LoRA 已经成功完成领域适配流程，并在部分指标上表现出正向变化，但还需要更大规模、更稳定的评测集来验证效果。
